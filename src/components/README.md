# Компоненты

Компонент, его тест и отдельный CSS лежат рядом. Импорты прямые, без общего index.js.

- ui — общие кнопки, поля, диалоги, аватары, скелетоны.
- app — оболочка приложения, навигация, ошибки, обновление, синхронизация.
- exercises — выбор, карточка, сканер, голос, техника и карта мышц.
- workout — действия тренировки, подходы, календарь, сохранение и экспорт.
- templates — выбор и редактирование подходов шаблона.
- progress — цели, личные рекорды и сравнение результатов.
- social — реакции, приглашения, фотографии обратной связи.
- auth — форма заявки и поле входа.
- onboarding — приветствие, быстрый старт, новости и привязка Telegram.
- notifications — запрос разрешения и настройки пушей.
- admin, circle, profile, recovery — компоненты соответствующих экранов.

Чистые вычисления остаются в src/lib, хуки — в src/hooks, доступ к данным — в src/db. Новый компонент помещайте в папку его функции; универсальный элемент без предметной логики — в ui.
