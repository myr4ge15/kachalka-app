# Чейнджлоги для друзей

Пользовательские анонсы обновлений (для чата, не для GitHub). Пишем на языке друзей,
без технички. Технические детали релиза — в `docs/BACKLOG.md` («Лог проходов»).

## Стиль (придерживаться)

- **Шапка:** под markdown-заголовком `## vX.Y.Z — Д месяца ГГГГ` идёт строка-шапка для Телеграма
  `🏋️ Что нового · vX.Y.Z · ДД.ММ.ГГГГ`, затем пункты.
  Версия — из `package.json`. (Пример — свежая запись ниже.)
- **Формат под Телеграм — два вида по размеру релиза** (всё это публикуется прямо в Телеграм,
  который сам рендерит `**жирный**` и оставляет дефис как маркер списка):
  - _Мелкий релиз_ (багфикс / пара правок) — **плоский список без буллетов**: каждый пункт с эмодзи
    в начале, пустая строка между пунктами, без подзаголовков (эталон — v3.10.4).
  - _Крупный релиз_ (много фич) — **группировка по темам**: вводная строка («Большой апдейт… Главное:»),
    затем тематические подзаголовки жирным, **БЕЗ эмодзи** (`**Свежесть по группам мышц:**`), под каждым —
    буллеты `- ` с ведущим эмодзи по смыслу пункта. Темы идут **по важности сверху вниз** (эталон формата —
    v3.18.0). Эмодзи живут только на буллетах, не дублируем их в подзаголовках.
- **Тон:** дружелюбный, коротко, по делу. Объясняем пользу, а не реализацию
  («аватарки не пропадают офлайн», а не «кэш в service worker»).
- **Эмодзи по смыслу пункта:** 🎨 дизайн · 📈 графики/прогресс · 🎯 цели · 🏆 рейтинг ·
  ⏱️ время · 🔑 вход · ✅ починка/защита · 📋 шаблоны · 🖼️ фото/аватар · 🔁 замена · 📤 экспорт.
- **Финал (по желанию):** лёгкий призыв — «Обновление прилетит само — просто переоткрой
  приложение 🙌» / «Залетайте, тестируйте, кидайте баги 🚀».
